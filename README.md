# 户型装修设计

中文 | [English](README.en.md)

纯前端的户型装修设计工具：在 2D 平面图上摆放家具、拆改墙体、测量尺寸，一键切换到 Three.js 3D 场景，可以鸟瞰，也可以第一人称漫游。户型本身也能在界面里直接改：导入一张户型图当底图描图，或者用鼠标拖墙、拖角点、画墙、画房间。整个应用就是一个 `index.html`，无需构建，打开即用。

## 功能

**2D 平面布置**
- 按原始户型 1:60 / 1:100 比例显示，尺寸单位 mm
- 从左侧家具库拖入 60 余种家具家电（卧室、客厅、餐厨、卫浴、家电、书房休闲）
- 拖动移动、旋转（Shift 自由角度）、调整尺寸，贴墙自动吸附
- 测量工具（靠近墙面自动吸附，Shift 锁定水平 / 垂直）
- 拆改非承重墙，承重墙单独标示
- 左侧「户型库」：承重墙、外墙、非承重墙、矮墙、各类房间、窗 / 飘窗 / 门 / 推拉门都能直接拖进图纸
- 「自动贴合」按钮一键开关吸附：墙体和房间自动贴到网格、已有墙线、相邻房间；网格疏密可选（10 / 50 / 100 / 250 / 500 mm、1 m），网格上标有单位
- 图层开关：尺寸标注、房间名、家具、网格、承重墙

**改户型（鼠标就能改）**
- 导入户型图：支持 PNG / JPG / WebP，导入后自动铺满户型范围，可调不透明度、拖动、拖角点缩放、锁定
- 两点标定比例：在图片上点两下并输入这段实际长度（mm），图片立刻缩放到真实尺寸，可以照着图描
- 拖虚线手柄 = 移动这根轴线：与它对齐的墙、门窗、房间边界一起移动，户型保持规整
- 拖房间角点（方块）= 同时移动经过该点的横竖两根轴线
- 拖墙体本身 = 整段墙平移，相接的墙自动伸缩，房间边界跟着走
- 画墙（拖一条线，可吸附到已有轴线）、画房间（矩形 / 多边形，双击或回车闭合）、开洞（沿墙拖出窗 / 门 / 推拉门，洞口不会滑出墙外）
- 点选任意墙、窗、门、推拉门、房间、户型图，右侧面板可改类型、尺寸、位置；门可翻转铰链 / 换开向，推拉门可切换推拉方向
- 选中任意墙、窗、门、推拉门或房间后按 `Delete` 直接删除（可撤销）；选择工具（`V`）下也能点选它们并拖手柄改尺寸
- 拖房间中心的圆手柄 = 整个房间平移：这个房间的一圈墙体（墙上的门窗一起）跟着走，**墙的厚度和长度完全不变**，贴着的飘窗一起移动；撞到相邻房间会自动停住，两个房间不会重叠
- 拖房间包围盒的四个角点（方块）= 直接改这个房间的尺寸：一圈墙始终贴合房间四周、厚度不变；最小 600 mm，涨不过相邻房间
- 一键布置家具：顶栏「🛋 一键布置家具」或右侧总览面板的同一按钮，按房间用途（卧室 / 客厅 / 餐厅 / 厨房 / 卫生间 / 洗衣 / 阳台）整套摆放；房间面板的「布置这个房间」只布置当前房间。家具自动贴墙、避开门洞、不会穿墙，布置完还能继续拖动微调
- 首次打开（或本地还没摆过家具）时会自动按房间用途摆好，不需要手动点；你自己摆过的方案不会被自动覆盖
- 从「户型库」拖入构件：落点附近有墙时，新墙自动延续那面墙的走向与厚度；房间的边缘自动贴到附近的墙线；门窗必须落在墙上（拖到空白处会提示）
- 墙体类型：承重 / 外墙 / 非承重可拆 / 矮墙；删墙、加墙、开洞后 2D 与 3D 同步，尺寸标注自动重排
- 所有改动都进撤销栈，方案存本地，也可导出 / 导入 JSON

**3D 场景**
- 鸟瞰、斜视、俯视多种视角，点击房间列表可飞到对应房间；**直接点房间里悬浮的房间名标签，视角也会平滑飞过去**（标签会高亮，2D 选中同步）
- 漫游模式：桌面端 WASD + 鼠标，触屏设备用虚拟摇杆；对准门点一下或按 `E` 开关门，走近门也能一键开关（关上的门还能再打开）
- 全高墙 / 剖切墙切换，日照时间滑块，夜景灯光
- 精细家具模型：柜门分缝与拉手、软包床头、带环境反射的金属与陶瓷材质等
- 在 3D 中也能选中、拖动家具，与 2D 方案实时同步

**方案与统计**
- 房间面积与套内使用面积自动统计
- 为每个房间更换地面材料（木地板、地砖、大理石、水磨石、地毯等），按面积加 5% 损耗估算造价
- 撤销 / 重做，方案自动保存在浏览器本地
- 中文 / English 界面切换（顶栏右侧按钮，默认中文，选择会记住）
- 导出 PNG 图片，导出 / 导入方案 JSON
- **导出 DXF 图纸（CAD 可直接打开，再另存为 DWG）**：墙 / 矮墙 / 门（含开启弧线）/ 窗 / 推拉门 / 玻璃 / 家具 / 房间名与面积 / 标注 / 户型图底图分 12 个图层，颜色按图层区分，1:1 毫米，随时可再进 CAD 修改

### 关于 DWG 和导出 DXF

- **为什么不是直接导出 .dwg**：DWG 是 Autodesk 的闭源二进制格式，写入需要 ODA Teigha / RealDWG 这类商业 SDK，浏览器里的单文件离线网页做不到。**DXF 是 DWG 的官方交换格式**，AutoCAD、中望 CAD、浩辰 CAD、天正、BricsCAD、LibreCAD 等都能直接打开本文件导出的 `户型装修平面图.dxf`；在 CAD 里 **另存为 → DWG** 即得到 .dwg。
- 导出的 DXF 是 **2007 版格式（AC1021）**：从 AutoCAD 2007 起 DXF 的文字统一用 UTF-8，所以中文（房间名、家具名、标题）是**正常汉字，不会乱码**，AutoCAD、中望 CAD、浩辰 CAD、BricsCAD 等 2007 以后的版本都按 UTF-8 读。
- 菜单里另有一项 **「导出 DXF（老版本 CAD 用 · R12）」**：给只认 R12 的老软件用，那份文件全部是纯 ASCII，中文改写成 AutoCAD 的 `\U+XXXX` 转义（`\U+4E3B\U+5367` = 主卧），不依赖代码页。默认那份乱码时再试这个。
- 平面图的 y 轴向下，导出的图纸已翻转成 CAD 的 y 轴向上，方向和屏幕上看到的一致。

## 快速开始

```bash
git clone <仓库地址>
cd <仓库目录>
```

然后直接用浏览器打开 `index.html`。也可以起一个本地静态服务器：

```bash
python3 -m http.server 8000
# 访问 http://localhost:8000
```

> Three.js 通过 jsDelivr CDN 加载，首次打开 3D 场景需要联网。

## 快捷键

| 按键 | 作用 |
| --- | --- |
| `T` | 切换 2D / 3D |
| `V` / `M` / `X` | 选择 / 测量 / 拆改墙体（选择工具下可点选墙体、房间、门窗） |

| `R` / `Shift+R` | 选中家具顺时针 / 逆时针旋转 90° |

| `Ctrl/⌘ + D` | 复制选中家具 |

| `F` | 适应窗口 |
| `+` / `-` | 放大 / 缩小 |
| `[` / `]` | 展开 / 收起左侧家具库、右侧面板 |

| `Esc` | 取消当前操作 |
| 漫游：`WASD` / 方向键，`Shift`，`E` | 移动，快走，开关门 |

## 技术栈

- 原生 HTML / CSS / JavaScript，无框架、无构建步骤
- 2D 平面图用 SVG 绘制
- 3D 场景用 [Three.js](https://threejs.org/) r160（OrbitControls、PointerLockControls、RoundedBoxGeometry、RoomEnvironment、CSS2DRenderer）
- 数据保存在 `localStorage`

## 改自己的户型

两种方式，都不用改代码：

1. **在界面里改**：顶栏「✎ 户型」进入户型编辑，按住手柄拖动墙体轴线、角点或墙段；也可以直接从左侧「户型库」把承重墙、外墙、房间、窗、门拖进图纸（拖入时自动吸附到网格和已有墙线）；「画墙 / 画房间 / 开洞」补齐结构；选中构件按 `Delete` 删除。3D 场景会同步重建。
2. **导入户型图照着描**：顶栏菜单 →「导入户型图」，图片铺在平面上，先用「两点标定比例」对准真实尺寸，再贴图描墙、描房间、开洞。

改完的方案存在浏览器本地，也可以用「导出 JSON」存成文件分享或在别的电脑导入。

## 自定义户型（改代码）

户型的初始数据写在 `index.html` 里（运行时改动会自动写回同一结构）：

- `ROOMS`：房间多边形、名称、默认地面材料
- `WALLS` / `WINS` / `DOORS` / `SLIDES`：墙体、窗洞、门、推拉门（运行时改动会写回 `state.plan` 一起保存）
- `MATS`：地面材料名称与单价
- `LIB`：家具库（类型、名称、默认尺寸、颜色）
- `buildFurniture()`：各类家具的 3D 模型

改这些数据就能换成自己的户型。
